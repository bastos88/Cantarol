🎤 Cantarol
Cantarol é um aplicativo web de karaokê que oferece uma experiência imersiva para os amantes da música. Com uma interface moderna e responsiva, o projeto visa proporcionar diversão e interação musical diretamente do navegador.

🚀 Funcionalidades
🎵 Catálogo de músicas: Navegue por uma seleção de faixas disponíveis para cantar.

🎤 Modo karaokê: Cante suas músicas favoritas com letras sincronizadas.

🎚️ Controles de áudio: Ajuste o volume e efeitos para aprimorar sua performance.

📱 Design responsivo: Compatível com dispositivos móveis e desktops.

🛠️ Tecnologias Utilizadas
HTML5 e CSS3: Estruturação e estilização das páginas.

JavaScript: Funcionalidades interativas e manipulação do DOM.

Web Audio API: Processamento e controle de áudio em tempo real.

Fontes e ícones personalizados: Para uma identidade visual única.
